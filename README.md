# Voxelings — политика конфиденциальности

Статический сайт для GitHub Pages: чистые HTML и CSS, без JavaScript, сборщиков,
внешних шрифтов, аналитики и cookies.

```
index.html      английская версия (основная)
ru/index.html   русская версия
style.css       общие стили
```

## Что заполнено

Дата вступления в силу, разработчик и контактный адрес вписаны в оба файла
(`index.html` и `ru/index.html`). Версии для iOS пока нет, поэтому в разделе
о разрешениях описан только Android — при выходе версии для iOS его нужно дополнить.

## Как включить GitHub Pages

1. Создайте на GitHub отдельный **публичный** репозиторий, например `voxelings-privacy`
   (на бесплатном тарифе Pages работает только для публичных репозиториев).
2. Загрузите в него файлы из этой папки:

   ```sh
   git init -b main
   git add .
   git commit -m "Privacy policy"
   git remote add origin https://github.com/<логин>/<репозиторий>.git
   git push -u origin main
   ```

3. В репозитории откройте **Settings → Pages**.
4. В блоке **Build and deployment** выберите **Source: Deploy from a branch**,
   ветку **main** и папку **/ (root)**, нажмите **Save**.
5. Через минуту-две на той же странице появится адрес сайта.

## Какой адрес вставлять в карточку магазина

```
https://<логин>.github.io/<репозиторий>/
```

Это английская версия — её и указывайте:

- **Google Play Console:** «Правила» → «Контент приложения» → «Политика конфиденциальности»
  (Policy → App content → Privacy policy).
- **App Store Connect:** раздел приложения App Privacy → поле Privacy Policy URL.

Русская версия доступна по адресу `https://<логин>.github.io/<репозиторий>/ru/`.
В App Store Connect её можно указать для русской локализации.

Перед вставкой откройте адрес в браузере в режиме инкогнито и убедитесь,
что страница открывается без входа в аккаунт.

## Как обновлять политику

Измените текст в обоих файлах, поставьте новую дату вступления в силу и отправьте
изменения в ветку `main` — сайт обновится сам. Адрес страницы при этом не меняется.
